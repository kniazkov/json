# JSON5 upstream parser cases

Source: https://github.com/json5/json5-tests/tree/ceb24d4080137d70833f86c25659c1331b80a387

MIT licensed; see LICENSE.md. All 114 .json/.json5/.js/.txt cases are included,
including the two Unicode cases in todo. cases.tsv contains relative path, expected
acceptance (true for .json/.json5), and Base64 of the original bytes, separated by tabs.
Base64 preserves actual control characters and line endings. Tests run offline.
